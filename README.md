# 設備点検システム

施設の設備点検（使用前点検・月例点検）をWebブラウザ上で行い、結果をPDF出力できるシステムです。  
デジタルサイネージ機能・文書閲覧機能も搭載しています。

> 画面写真入りの説明（入れ方・サンプルでの試し方・毎日の使い方）は [取扱説明書](docs/manual/取扱説明書.md)（[PDF版](docs/manual/取扱説明書.pdf)）にあります。

## セットアップ

**ふつうは `初回セットアップ.bat` をダブルクリックするだけで済みます**（下の1・2を自動で行います）。
コマンドで行う場合は、以下の手順です。

### 1. Python仮想環境の作成（初回のみ）

コマンドプロンプトで以下を実行します（`（アプリのフォルダ）` は、このREADMEがあるフォルダに置き換えてください）。

```cmd
cd （アプリのフォルダ）
python -m venv .venv
```

### 2. 必要パッケージのインストール（初回のみ）

```cmd
.venv\Scripts\pip.exe install -r requirements.txt
```

インストールされるパッケージ：

| パッケージ | 用途 |
|---|---|
| flask | Webサーバー |
| filelock | ファイル排他制御 |
| jpholiday | 日本の祝日判定 |
| reportlab | PDF生成 |
| waitress | 本番用サーバー |
| pytest | テスト実行 |

## 起動方法

**ふつうは `起動.bat` をダブルクリックします。** 数秒後に Edge が `http://localhost:5000` を開きます。

### コマンドプロンプトの場合

```cmd
cd （アプリのフォルダ）
.venv\Scripts\python.exe app.py
```

### 起動後

以下のメッセージが表示されます。

```
設備点検システムを起動します...

（waitressサーバーで起動）
```

**ブラウザで `http://localhost:5000` にアクセス**してください。

### 終了方法

コマンドプロンプトで `Ctrl + C` を押します。

## 画面構成と使い方

### 🖥️ サイネージ画面（トップページ）

`http://localhost:5000/`

- 指定フォルダ内のPDFファイルを自動スライドショーで表示します
- 左右スワイプ / ドラッグ / 矢印キーで手動切り替え可能
- 指定時刻になると自動でスリープモード（時計表示）に切り替わります
- 画面右上の ⚙ ボタンで表示設定を変更できます

### 📋 点検画面

`http://localhost:5000/inspection`

#### 使用前点検（日常点検）

1. 画面上部のタブで**大分類**（例: 設備A、クレーン）を選択
2. サブタブで**小分類**（例: A-1、A-2）を選択
3. 各点検項目に対して次の5つから選択

   | 記号 | 意味 |
   |---|---|
   | ✓ | 良 |
   | A | 要調整 |
   | △ | 修理 |
   | × | 要取替 |
   | ー | 点検対象外 |

   A・△・× のいずれかを付けて保存すると、不合格の警告が出ます。

4. テーブル下部で**部署**と**点検者名**を選択
5. **💾 保存** ボタンを押して完了

> **ショートカット**: 数字キー（1〜9）で点検者を選択、`*` キーで全て✓にできます

> **使用せず**: 使用前点検で、その日の24時を過ぎても点検の記録が無い日は、
> 点検表・様式PDFの「使用せず」欄に自動で ✓ が入ります（当日と未来の日は空欄のまま）。
> あとから過去の日を入力すれば、✓ は消えて点検結果に置き換わります。

> **以前の記録について**: 仕様変更前に「○」で保存された記録は、そのまま「良（✓）」として
> 表示・印刷されます。保存済みのファイルは書き換えません。

#### 月例点検

1. 画面左上のタブで「月例」に切り替え
2. 点検日を選択（使用前と異なり任意の日付を指定可能）
3. 使用前と同様に ✓ / A / △ / × / ー を選択して保存

#### PDF出力

- 画面右上の **📄 PDF** ボタンで、当月の点検結果PDFをダウンロード
- 使用前点検と月例点検の両方が含まれます
- 同時に特記事項のCSVファイルもダウンロードされます

> **注意**: PDF出力には、全設備の点検が完了している必要があります

### 📁 文書閲覧画面

`http://localhost:5000/documents`

- 設定で指定したフォルダ内のPDFファイルをブラウザ上で閲覧できます
- ピンチズーム / ホイールズーム対応
- カテゴリ（最大5つ）ごとにフォルダを設定可能

### 🌐 Web表示画面

`http://localhost:5000/webview`

- 設定で登録した外部Webページをiframeで表示します

### 🗂 様式レイアウト画面

`http://localhost:5000/layout`（点検画面の右上「🗂 様式レイアウト」からも開けます）

会社で使っている紙の点検表（PDF）に、点検結果を直接印字するための設定画面です。
「この欄にはこの点検項目の判定」「この欄には日にち」のように、**どこに何を書くか**をマウスで指定します。

> **アプリを動かしているPCで開いてください。** 他のPCから開くと管理者権限が無いため使えません。

1. **新しい様式を追加** … 4つの手順で、PDFファイル → 様式の種類（1枚に1か月分／1枚に1年分／1回の点検で1枚）→ 対象の機器 → 様式名と点検種別（使用前／月例）の順に選びます
2. **項目を置く** … 左の一覧から項目を選び、様式の上をクリックすると配置されます。右パネルで文字の大きさや位置を細かく直せます
3. **並び方を指定する** … 日付ごとに横に並ぶ欄は、画面下の「1日目のマスを指定」「2日目のマスを指定」（1年分の様式では「1月目」「2月目」）でマスの間隔を決めると、マスの数だけ自動で繰り返します
4. **試し刷り** … 見本のデータで印字したPDFを開いて、位置を確かめます（建物名は常に「見本ビル」と出ます）
5. **保存** … 置いていない項目が残っていると警告が出ます

- 作った様式は様式フォルダ（既定はアプリ内の `forms/`。設定画面で変更可）に `form_01`、`form_02`…の名前で自動で保存されます
- 「この様式を削除」は完全には消さず、様式フォルダ内の `.trash/` に移すだけです
- 点検結果PDF（点検画面の 📄 PDF出力）は、1枚目が特記事項、2枚目以降が様式、最後が従来の表の順に並びます。様式の順番は点検画面の設定（⚙）の「様式の並び順」で ▲▼ を押して変えられます

## マスタデータの編集

`data` フォルダ内のCSVファイルをテキストエディタまたはExcelで編集します。

### equipment_master.csv（設備マスタ）

点検対象の設備と点検項目を定義します。

| 列名 | 説明 | 例 |
|---|---|---|
| `category_major` | 大分類 | クレーン、設備A |
| `category_minor` | 小分類 | A-1、クレーン1 |
| `inspection_item` | 点検項目 | 変形していないか |
| `inspection_type` | 種別 | `使用前` / `月例` / `両方` |

```csv
category_major,category_minor,inspection_item,inspection_type
設備A,A-1,変形していないか,使用前
設備A,A-1,オイルは漏れていないか,使用前
クレーン,クレーン1,点検項目C-1,月例
設備B,B-1,点検項目B-1,両方
```

### inspectors.csv（点検者マスタ）

点検を行う担当者の一覧を定義します。

| 列名 | 説明 | 例 |
|---|---|---|
| `inspector_name` | 氏名 | 管理 太郎 |
| `department` | 部署 | 施設管理部 |

```csv
inspector_name,department
管理 太郎,施設管理部
鈴木 花子,設備管理課
```

### custom_holidays.csv（独自休日）

会社独自の休日を定義します（祝日は自動判定されるため不要）。

| 列名 | 説明 | 例 |
|---|---|---|
| `date` | 日付（YYYY-MM-DD） | 2026-03-20 |
| `name` | 休日名 | 創立記念日 |

```csv
date,name
2026-03-20,創立記念日
2026-05-01,メーデー
```

> **注意**: CSVファイルの文字コードは **UTF-8（BOM付き推奨）** で保存してください

## 設定の変更

### 画面上から変更する方法

- **点検画面**: 右上の ⚙ ボタン → 設定モーダルが開きます
- **サイネージ画面**: 右上の ⚙ ボタン → 設定パネルが開きます

### config.json の設定項目

`config.json` を直接編集することもできます（サーバー再起動が必要）。

> `config.json` はダウンロード直後にはありません（現場ごとの設定なので Git では管理していません）。無いあいだは既定の設定で動き、画面の ⚙ で設定を保存したときに作られます。

| 項目 | 説明 | デフォルト値 |
|---|---|---|
| `save_directory` | 点検結果の保存先フォルダ | `results/`（空欄時） |
| `server.host` | サーバーのホスト | `127.0.0.1` |
| `server.port` | サーバーのポート番号 | `5000` |
| `signage.folder_path` | サイネージ用PDFフォルダ | `signage_pdfs/`（空欄時） |
| `signage.display_seconds` | スライド表示秒数 | `5` |
| `signage.sleep_start` | スリープ開始時刻 | `18:00` |
| `signage.sleep_end` | スリープ終了時刻 | `08:00` |
| `signage.idle_return_seconds` | 操作なし時にサイネージへ戻る秒数 | `30` |
| `building_info.building_name` | 建物名（PDF・画面に表示） | — |
| `building_info.managers` | 管理者情報（最大3名） | — |
| `document_categories` | 文書カテゴリ設定（最大5つ） | — |
| `web_pages` | Web表示用ページ（最大2つ） | — |

### 他端末からアクセスさせる場合

`config.json` の `server.host` を `0.0.0.0` に変更すると、同一ネットワーク内の他の端末からもアクセスできます。

```json
"server": {
    "host": "0.0.0.0",
    "port": 5000
}
```

この場合、リモートからの設定変更には**管理者キー**（起動時にコンソールに表示されます）が必要です。

## トラブルシューティング

### 起動時に「ポートが使用中」と表示される

他のアプリケーションがポート5000を使っている場合、自動的に別のポート（5001〜5009）で起動します。  
コンソールに表示されるURLを確認してください。

### PDFが表示されない

- サイネージ用PDFフォルダ（`signage_pdfs/` または設定で指定したフォルダ）にPDFファイルが置かれているか確認してください
- ファイルの拡張子が `.pdf`（小文字）であることを確認してください

### 点検結果が保存できない

- `results/` フォルダ（または設定で指定した保存先）に書き込み権限があるか確認してください
- ログファイル（`logs/app.log`）にエラーメッセージが記録されています

### CSVを編集したのに反映されない

- CSVファイルの文字コードが **UTF-8** であることを確認してください
- Excelで保存する場合は「CSV UTF-8」形式を選択してください
- サーバーの再起動は不要です（CSVは毎回読み込まれます）

### テストの実行方法

```cmd
cd （アプリのフォルダ）
.venv\Scripts\python.exe -m pytest tests/ -v
```
