# 開発記録（設計書・実装計画）

このフォルダは、機能を追加したときの設計書（`specs/`）と実装計画（`plans/`）をそのまま残したものです。
アプリを使うだけなら読む必要はありません。使い方は [`docs/manual/取扱説明書.md`](../manual/取扱説明書.md) を見てください。

## 読むときの注意

- **当時の仮データを前提に書いています。** 例やテストのコードに出てくる `設備A`・`クレーン1`・`sample_daily`・`仮ビル 本館` などは、開発中に使っていた仮の名前です。いまの `data/` と `samples/` のサンプル（サンプル工業 第一工場・天井クレーン1号機 など）とは名前が違います。
- **古い版の名前（ver3 など）が出てきます。** いまのアプリの版数は `app.py` の `APP_VERSION` だけが正です。
- **書いた時点の記録です。** その後の変更で実際のコードと食い違っている箇所があります。いまの決まりはリポジトリ直下の `CLAUDE.md` と `README.md` が正です。
